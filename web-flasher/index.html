Before flashing
  1. Use a data USB cable and close Serial Monitor/Arduino IDE.
  2. Select COM19 / USB-Enhanced-SERIAL CH343.
  3. If missing, hold BOOT, tap RESET, then release BOOT.
  4. Do not disconnect power while writing.
